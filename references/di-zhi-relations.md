## 一、地支六合（爻层面）

| 六合配对 | 合化 |
|----------|------|
| 子丑合 | 土 |
| 寅亥合 | 木 |
| 卯戌合 | 火 |
| 辰酉合 | 金 |
| 巳申合 | 水 |
| 午未合 | 土 |

**断点**：
- 爻爻相合 → 彼此牵绊，作用暂缓，逢冲方解
- 日月合爻 → 该爻被合绊，暂不能生克他爻
- 动爻与变爻相合 → 动而逢合，事有羁绊
- 用神逢合 → 吉则拖延，凶则暂不发作
- **合处逢冲** → 先合后散，事成复败
- **冲处逢合** → 先散后合，冲突得调

**六合深断模板（铁律 11，禁止只写「合则绊住」）**：
1. **定合的来源**：爻爻合、日月合爻、动爻化合、世应合、用神合、忌神合、卦逢六合、六冲化六合、合变合分别标明；爻层六合不得混作六合卦。
2. **定参与角色**：逐一列参与爻的爻位、六亲、地支、五行、世应、动静、旬空/月破/旺衰；注明它是用神、原神、忌神、仇神、泄气爻、辅助用神还是闲神。
3. **定合化五行与合中生克**：写明合化何五行；再判断合化之五行对用神是生、克、泄、耗、比和，且判断合中有生还是合中有克。不可见合即断吉。
4. **定合住谁**：用神被合为事情被拖住；原神被合为援力暂缓；忌神被合为凶力暂缓；仇神被合为间接减害；应爻被合为对方受牵制；世爻被合为我方受牵制。
5. **定释放点**：合处逢冲必列冲开之支（日/月/年）；若合化成局须列成局条件；若合中有克须说明冲开后克力是否复现。
6. **落断语**：说明此合对所问之事是拖延、牵制、保护、助忌、制忌、成事还是败事；只写「有牵缠」为漏断。

**六合取象速断**：
- 用神旺而被吉合：成事但慢，待冲开/合实应事。
- 用神休囚被合：未必吉，可能被绊住无力行动。
- 忌神旺而被合：短期为救，冲开后须防忌神复克。
- 原神被合：援助有、但来得慢；待冲开或合实。
- 合化之五行助忌神：合反为凶；合化之五行制忌神或生用神：合可为救。

## 二、地支三合局

三合局是六爻中最强大的联动关系，力量远超单爻生克。只有动爻（含暗动）与日月方可组成。

| 三合局 | 属性 | 长生→帝旺→墓库 |
|--------|------|-----------------|
| 申子辰 | 水局 | 申(长生) 子(帝旺) 辰(墓库) |
| 亥卯未 | 木局 | 亥(长生) 卯(帝旺) 未(墓库) |
| 寅午戌 | 火局 | 寅(长生) 午(帝旺) 戌(墓库) |
| 巳酉丑 | 金局 | 巳(长生) 酉(帝旺) 丑(墓库) |

**成局条件（⛔ 用户 2026-09-19 明定口径，paipan.py 同此；三合三会共用，唯一差别见下）**：

> 📌 **总纲**：**激活源** = ① 任一爻发动 ② **日月入组**（日辰或月建占局中一字）。**有激活源即成局**；**无激活源（全静且日月不入组）→ 虚合**。
> ⛔ **三合与三会的唯一差别**：**三会多一个最高档「严格成局」＝三爻全动**；**三合没有这个最高档**（三合即使三爻全动，也只是「成局」）。

1. **全静（三爻皆不发）** → 必为**虚合**；**必须日月来一个**（日辰或月建占局中一字）方成局。日月不来，即便三字全现也只是虚合（合而不化、三支互相牵制减力迟滞）
2. **日月都不入组 ＋ 有一爻发动** → **即成局**（动爻本身即激活源）
3. **二字实、一字空亡**：该空字**逢值日/值月之时，即等于日月入卦**，也就等于它发动了 → 故此时为**虚合待时**，应期即「该空字值日/值月」，届时自动成局（JSON `void_trigger` 字段标出此时机）
4. **三字到位**：三支全在卦内，或二字现＋日月补缺字（日月权柄可把缺的一支"带进来"）；**变爻亦可作补字**（动爻化出缺字 → 合局成形，实战已验证）
5. **半合（二字现＋有动且缺字未补）**：见下表子型；二字全静且日月不补 → 不作合论
6. **静爻参与**：静爻须得日月引动（日合/月合/日冲暗动等）才计入合局；纯粹无日月关照的静爻作旁观论
7. 一切以 `paipan_result.json` patterns.sanhe_ju 的 status 为准，禁止手动重新识别（铁律 13）；变爻/日月补字属解读层升级标注，与 JSON 基线并存

> ⛔ **空亡不作独立状态档**：局中一字旬空**不降级**（旧「空亡压死」写法已废，JSON 也不再出现「三会」这一档），仅记入 `kong_positions` 表示**局力打折**——该字为动爻则动则不空、不减力；为静爻则出空补足。全静且日月不入组而有空亡时，`void_trigger` 标出激活时机（即上述第 3 条）。

**半合子型**（二字现＋有动）：
| 二字 | paipan 子型 | 俗称 | 待补字 |
|------|-------------|------|--------|
| 长生+帝旺（如申子） | 长生帝旺 | 生地半合 | 墓库（辰） |
| 帝旺+墓库（如子辰） | 帝旺墓库 | 墓地半合 | 长生（申） |
| 长生+墓库（如申辰） | 长生墓库 | 拱合（隔位） | 帝旺（子） |

**断点（必须判断加强何爻，铁律 11）**：
1. **定局五行**：申子辰=水、亥卯未=木、寅午戌=火、巳酉丑=金
2. **定所强六亲**：以本卦宫五行为「我」——局五行生我=父母局、克我=官鬼局、同我=兄弟局、我生=子孙局、我克=妻财局（如寅午戌火局、乾宫属金→火克金=官鬼局）
3. **找所强之爻**：卦内（含动爻变爻、日月同位）与局五行同气之爻即受强之爻，逐爻列出六亲+爻位；连带生克一并交代（局五行所生/所克的其他六亲）
4. **断吉凶**：所强之爻=原神→助用神，吉；=忌神→克用神，凶；=用神→用神极旺；=泄用神者→用神被泄耗（先耗后得/耗财耗力之象）
5. **缺字/旬空/冲散**：三合局一字被冲散 → 合局破裂，吉凶皆解；缺一字半合 → 注明待补之字（变爻/日月已补则升级，未补则逢值逢合之日/年成局）；局中一字旬空 → 局力打折（该字为动爻则动则不空、不减力；静爻空则出空补足）
6. **定成员角色**：局中每一字必须标明来自日、月、动爻、静爻、变爻还是太岁；对应六亲角色必须写清。太岁/月日补字属于时间层增强，须与 JSON 基线并存，不得私改 patterns。

## 三合 vs 三会：区别速查与应用要点

| 对比项 | 三合局 | 三会局 |
|--------|--------|--------|
| 组合逻辑 | 长生＋帝旺＋墓库（**跨季节**拉拢） | 同方同季**相邻三支**（本气齐聚） |
| 力量 | 强 | **最强**（同气纯聚，一般大于三合） |
| 核心字 | **帝旺为枢纽**，缺之难成局 | 无帝旺之说，三支齐备即成，缺一则力减 |
| 半合/半会 | 有生地半合/墓地半合/拱合 | **不论半会**（相邻两支力量极弱，不作会看） |
| 成局难度 | 灵活（半合、拱合、日月补字均可论） | 严（须三支齐全） |
| 六爻权重 | **常用**，三合为大 | 少见，一旦出现合力更猛，**断卦权重加大** |

**共同要点**：
1. **成局激活源（同一口径）**：**动爻** 或 **日月入组**，二者居其一即成局；全静且日月不入组则为虚合/三会之势（详见第二、三节）。三合缺字另可由变爻补全，三会成员仅计主卦爻
2. **⛔ 最高档之别**：三会三爻全动 → **严格成局**；三合三爻全动 → **仍是成局**。这是两节唯一的判定差别，不得互相套用
3. **成局≠吉**：合化出的五行对用神是生是克、是助是泄，才是吉凶核心——**合局化出忌神五行则「合」反为凶**，切忌见合即断吉
4. **破局**：合局遇冲（尤其冲中间枢纽字：三合冲帝旺、三会冲中支）→ 合局动摇；日建月建可「合起」卦中之爻，也可**冲破合局**，冲破则不论合
5. **应期**：局中缺字未到位 → 逢值、逢合之日/月为应期（如亥卯未缺亥 → 亥日/亥年成局）；**全静且日月不入组而局中一字空亡 → 该字值日/值月即成局**（空字值日月＝日月入卦＝发动）
6. **合而不化**：虚合/三会之势按「合绊」论——牵制、减力、迟滞，不按成局吉凶论
7. **太岁/月日补局**：长期占断时，太岁补缺字是年级别强信号；月建/日辰补缺字是月日级别触发。必须说明是「成局应期」还是「局力增强」，不得把未来补字当作当前已成局。

## 四、地支六冲（爻层面）

| 六冲配对 |
|----------|
| 子午冲 |
| 丑未冲 |
| 寅申冲 |
| 卯酉冲 |
| 辰戌冲 |
| 巳亥冲 |

**爻爻相冲 ≠ 六冲卦**：六冲卦（如乾为天）是卦的结构属性；爻爻相冲是局部关系。

**断点**：
- 用神逢冲 → 事有变动
- 世应相冲 → 双方对立
- 动爻逢月冲 → 月破
- 静爻旺相逢日冲 → 暗动

**六冲深断模板（铁律 11，禁止只写「冲则变动」）**：
1. **定冲的来源**：爻爻冲、日月冲爻、动变冲、世应冲、卦逢六冲、六合变六冲、六冲变六合、冲散三合/三会局分别标明；爻层六冲不得混作六冲卦。
2. **定参与角色**：逐一列冲的双方爻位、六亲、地支、五行、世应、动静、旬空/月破/旺衰；注明它是用神、原神、忌神、仇神、泄气爻、辅助用神还是闲神。
3. **定强弱**：旺相有气者逢冲多为冲起、冲动、不散；休囚空破者逢冲多为冲破、冲散；动爻逢冲须结合「动不为破」判断。
4. **定冲的性质**：冲用神、冲原神、冲忌神、冲仇神、冲世、冲应、冲开合绊、冲散合局、冲破弱爻，各有不同吉凶。忌神仇神宜冲，用神原神不宜被冲破。
5. **定应期**：被冲之支、冲出之支、合处逢冲、冲处逢合、月破出月、日冲暗动/日破均须列入应期判断。
6. **落断语**：说明此冲对所问之事是加速、破局、冲开阻碍、引发冲突、冲起行动还是冲破根基；只写「有变动」为漏断。

**六冲取象速断**：
- 忌神旺而冲用神：外力来伤，须看用神是否旺相可承冲。
- 用神旺而冲忌神：主动破阻，冲可为用。
- 忌神被冲散：凶力减退，但逢值旺时仍可复起。
- 原神被冲破：援力受损；原神旺相逢冲则援力被激发。
- 合绊被冲开：短期解绊，但若被合住的是忌神，冲开后忌神可能复克。
