## 一、地支六合（爻层面）

| 六合配对 | 合化 |

| 子丑合 | 土 |
| 寅亥合 | 木 |
| 卯戌合 | 火 |
| 辰酉合 | 金 |

**断点**：
- 爻爻相合 → 彼此牵绊，作用暂缓，逢冲方解
- 日月合爻 → 该爻被合绊，暂不能生克他爻
- 动爻与变爻相合 → 动而逢合，事有羁绊

- **合处逢冲** → 先合后散，事成复败
- **冲处逢合** → 先散后合，冲突得调

## 二、地支三合局

三合局是六爻中最强大的联动关系，力量远超单爻生克。只有动爻（含暗动）与日月方可组成。

| 三合局 | 属性 | 长生→帝旺→墓库 |
|--------|------|-----------------|
| 申子辰 | 水局 | 申(长生) 子(帝旺) 辰(墓库) |
| 亥卯未 | 木局 | 亥(长生) 卯(帝旺) 未(墓库) |
| 寅午戌 | 火局 | 寅(长生) 午(帝旺) 戌(墓库) |
| 巳酉丑 | 金局 | 巳(长生) 酉(帝旺) 丑(墓库) |

**成局条件（本技能取「一动＋日月补齐」派，与 paipan.py 检测逻辑一致）**：
1. **先查日月，再看动爻（含变爻）**：月建、日辰地支＋动爻（或动爻化出之变爻）地支能凑齐三支即论成局——日月权柄大于动爻，可把缺的一（两）支"带进来"；**变爻同样可作补字**（如动爻化出缺字 → 合局成形，实战已验证）
2. **三字全现**：≥1 动 → 成局；全静但日月占其中一字（日月引动）→ 成局；全静且日月不占 → **虚合**（合而不化，三支互相牵制、减力迟滞）
3. **二字现（半合）**：有动 → 半合（子型见下表）；二字全静且日月不补 → 不作合论。**半合＋缺字被变爻/日月补上 → 升级为合局**（解读层标注，paipan JSON 基线仍为半合，不得改动）
4. **静爻参与**：静爻须得日月引动（日合/月合/日冲暗动等）才计入合局；纯粹无日月关照的静爻作旁观论
5. 一切以 `paipan_result.json` patterns.sanhe_ju 的 status 为准，禁止手动重新识别（铁律 13）；变爻/日月补字属解读层升级标注，与 JSON 基线并存

**半合子型**（二字现＋有动）：
| 二字 | paipan 子型 | 俗称 | 待补字 |
|------|-------------|------|--------|
| 长生+帝旺（如申子） | 长生帝旺 | 生地半合 | 墓库（辰） |
| 帝旺+墓库（如子辰） | 帝旺墓库 | 墓地半合 | 长生（申） |
| 长生+墓库（如申辰） | 长生墓库 | 拱合（隔位） | 帝旺（子） |

**断点（必须判断加强何爻，铁律 11）**：
1. **定局五行**：申子辰=水、亥卯未=木、寅午戌=火、巳酉丑=金
2. **定所强六亲**：以本卦宫五行为「我」——局五行生我=父母局、克我=官鬼局、同我=兄弟局、我生=子孙局、我克=妻财局（如寅午戌火局、乾宫属金→火克金=官鬼局）
3. **找所强之爻**：卦内（含动爻变爻、日月同位）与局五行同气之爻即受强之爻，逐爻列出六亲+爻位；连带生克一并交代（局五行所生/所克的其他六亲）
4. **断吉凶**：所强之爻=原神→助用神，吉；=忌神→克用神，凶；=用神→用神极旺；=泄用神者→用神被泄耗（先耗后得/耗财耗力之象）
5. **缺字/旬空/冲散**：三合局一字被冲散 → 合局破裂，吉凶皆解；缺一字半合 → 注明待补之字（变爻/日月已补则升级，未补则逢值逢合之日/年成局）；局中一字旬空 → 局力打折（该字为动爻则动则不空、不减力；静爻空则出空补足）
6. 第七步综合断语必须引用上述结论——铁律 11 四要素：成局状态/所强之爻/对用神吉凶/结果断语

## 三、地支三会局

| 三会局 | 属性 | 组成 |
|--------|------|------|
| 寅卯辰 | 东方木 | 寅+卯+辰 |
| 巳午未 | 南方火 | 巳+午+未 |
| 申酉戌 | 西方金 | 申+酉+戌 |
| 亥子丑 | 北方水 | 亥+子+丑 |

**成局状态（以 paipan.py 四档状态机为准，禁止手动重新识别，铁律 13）**：

| 状态 | 判定 |
|------|------|
| 严格成局 | 3 支全动，或 2 动＋日月补第三字 |
| 成局 | ≥1 动且局中无旬空；或 全静＋日月入组且无旬空 |
| 三会 | ≥1 动但局中一字旬空（动爻不空，空在它爻）→ 出空自动升级成局 |
| 三会之势 | 全静＋日月不在组；或 全静＋日月入组但局中一字旬空（空亡压死，出空也只是势） |

- 三会与三合取法统一：**一爻动＋日月入组即可成局**，不苛求三支皆动
- **缺一字不作会**：三会不论半会——相邻两支（如只现巳午）力量极弱，不作会看；**成员仅计主卦爻（含日月同位），变爻/伏神不计入**（与 paipan 检测一致）
- 静爻同三合：须日月引动才参与

> ⛔ **措辞随状态走**：status=严格成局/成局 → 可用绝对化措辞；status=三会/三会之势 → 必须注明限制（一字旬空/全静无日月引动），不得用「碾压」「势不可挡」等绝对化措辞；出空/出月后状态升级的，注明「出空成局」。

**认定报告（须在第三步输出中显式呈现，status 须与 JSON patterns.sanhui_ju 一致）**：
```
三会局认定：
- 三方：[X]（[动/静/变/日月]）、[Y]（[状态]）、[Z]（[状态]）
- 状态（读 JSON）：[严格成局 / 成局 / 三会 / 三会之势]
- 一字旬空（如有）：[字+爻位，出空成局/空亡压死]
```

三会局一旦严格成局，方向性极强，无论生克势不可挡。三会之势虽降级，合力仍远超单爻生克。

**断点（必须判断加强何爻，铁律 11；方法同三合局断点）**：
1. **定局五行**：寅卯辰=东方木、巳午未=南方火、申酉戌=西方金、亥子丑=北方水
2. **定所强六亲**：以本卦宫五行为「我」——局五行生我=父母局、克我=官鬼局、同我=兄弟局、我生=子孙局、我克=妻财局（如巳午未火局、乾宫属金→火克金=官鬼局）
3. **找所强之爻**：卦内与局五行同气之爻即受强之爻，逐爻列出六亲+爻位；连带生克一并交代（局五行生父母/克官鬼等）
4. **断吉凶**：所强之爻=原神→助用神，吉；=忌神→克用神，凶；=用神→用神极旺；=泄用神者→用神被泄耗（先耗后得/耗财耗力之象）
5. **局中一字旬空/月破**：局力打折，须注明「出空/出月即实」（该字为动爻则动则不空、不减力）；局字被冲散 → 合局破裂
6. 第七步综合断语必须引用本断点结论——铁律 11 四要素：成局状态/所强之爻/对用神吉凶/结果断语

## 三合 vs 三会：区别速查与应用要点

| 对比项 | 三合局 | 三会局 |
|--------|--------|--------|
| 组合逻辑 | 长生＋帝旺＋墓库（**跨季节**拉拢） | 同方同季**相邻三支**（本气齐聚） |
| 力量 | 强 | **最强**（同气纯聚，一般大于三合） |
| 核心字 | **帝旺为枢纽**，缺之难成局 | 无帝旺之说，三支齐备即成，缺一则力减 |
| 半合/半会 | 有生地半合/墓地半合/拱合 | **不论半会**（相邻两支力量极弱，不作会看） |
| 成局难度 | 灵活（半合、拱合、日月补字均可论） | 严（须三支齐全） |
| 六爻权重 | **常用**，三合为大 | 少见，一旦出现合力更猛，**断卦权重加大** |

**共同要点**：
1. **先查日月，再看动爻**：月建、日辰地支优先，再看动爻——动爻＋日＋月凑齐三支即论成局（本技能取「一动＋日月补齐」派，三合三会同一标准，paipan.py 同此逻辑；三合缺字另可由变爻补全，三会成员仅计主卦爻）
2. **成局≠吉**：合化出的五行对用神是生是克、是助是泄，才是吉凶核心——**合局化出忌神五行则「合」反为凶**，切忌见合即断吉
3. **破局**：合局遇冲（尤其冲中间枢纽字：三合冲帝旺、三会冲中支）→ 合局动摇；日建月建可「合起」卦中之爻，也可**冲破合局**，冲破则不论合
4. **应期**：局中缺字未到位 → 逢值、逢合之日/月为应期（如亥卯未缺亥 → 亥日/亥年成局）
5. **合而不化**：虚合/三会之势按「合绊」论——牵制、减力、迟滞，不按成局吉凶论
