# 高级应期法则

> 补充主 Skill 第六步的基本应期推断。以下法则按优先级排列。

---

## 法则速查

| 优先级 | 法则 | 条件 | 应期 |
|--------|------|------|------|
| 1 | 合处逢冲 | 被合之爻 | 逢冲合爻之日（如子丑合→午日冲子或未日冲丑） |
| 2 | 冲处逢合 | 被冲之爻 | 逢合冲爻之日（如子午冲→丑日合子或未日合午） |
| 3 | 绝处逢生 | 用神逢绝地 | 遇生扶之日月（如金绝于寅→遇土月土日） |
| 4 | 入墓待冲 | 用神入墓 | 逢冲墓之日（如辰墓→逢戌日） |
| 5 | 动而逢合 | 动爻被日合 | 冲开合绊之日 |
| 6 | 伏神待出 | 用神伏藏 | 冲飞神之日，或伏神值日 |
| 7 | 三合缺字 | 三合局缺一字 | 缺字之日即应期 |
| 8 | 化进神 | 动爻化进 | 逢值之日（进神地支再现） |
| 9 | 化退神 | 动爻化退 | 逢冲之日（冲动退神则退速） |
| 10 | 动而化空 | 动爻化旬空之变爻 | 出空/填空之日 |
| 11 | 动而化破 | 动爻化月破之变爻 | 出月不破，或填实之日 |
| 12 | 用被合绊 | 用神被日月/动爻合 | 冲开合爻之日 |

> ⛔ **「逢冲之日」措辞区分**：用神安静逢冲为应期时（基本法则第 6 条）：
> - 用神**旺相**被冲 → **冲起**（如暗动，被唤醒而非击破，反得更强），措辞写「冲起」非「冲动」
> - 用神**休囚**被冲 → **冲破**（如日破，被冲散无力），措辞写「冲破」非「冲动」
> - 「冲动」为模糊用语，仅用于无法判定旺衰时的兜底措辞

> 🚨 **主应期不得被辅助触发点淹没（v1.9.2）**：应期输出必须分「主应期 / 辅助节点 / 风险窗口」。用神中和或旺相、不空不破时，除「安静逢冲」外，必须检查并列出用神临值月/日；用神兼世爻、驿马或所问核心六亲时，临值优先级不低于逢冲。六合冲开、三合缺字、动爻逢值、化空出空等先归入辅助节点，只有直接作用用神、世爻或核心辅助用神才升为主应期。忌神临值/出空/冲用神单列风险窗口。

## 应期单位选择

- 月建层面 → 应在何月（节气）
- 日辰层面 → 应在何日（干支）
- 时令层面 → 应在何时辰

**判断口诀**：急事看日（如失物、疾病、出行），缓事看月（如求职、婚嫁），远事看年（如投资回报、须数年之功者）。

## 常见应期取象

| 场景 | 应期倾向 |
|------|----------|
| 出行 | 应于冲动之日月 |
| 文书/考试 | 应于父母爻旺相之日月 |
| 求财 | 应于妻财爻当值/出空/合绊解开之日月 |
| 官运/跳槽 | 官鬼临值主职位落地；父母旺相/逢值/逢冲/出空主 offer、合同、审批；妻财当值/出空主待遇落实；三者须分层输出 |
| 感情 | 应于桃花月（卯月）或合处逢冲之日月 |
| 疾病 | 应于官鬼入墓/绝之日月（愈）；忌神旺相之日月（危） |
| 诉讼 | 应于官鬼冲克之日月 |

## 场景应期角色分层表（frv v1.8.3，同构 main v1.9.3）

> ⛔ 第六步必须先按 intent 查本表，再结合用神旺衰、空破、动变、合冲、三合三会等法则排应期。不得只按地支触发点平铺月份。若实际问法跨多个 intent，取各相关行的并集，并标明哪一层决定成败、哪一层只影响过程。表中角色是「检查清单」不是死板取用：卦中不现、与本题无关或已由用户指定其他用神时，必须在对应层写明不适用或升降级理由。

| intent | 主应期（决定所问之事） | 辅助节点（流程/条件成熟） | 风险窗口（阻力/破局/反复） |
|--------|------------------------|--------------------------|----------------------------|
| 求财 | 妻财临值、出空、得生、合绊解开 | 子孙旺动生财、原神出空/临值、父母项目文书落实 | 兄弟临值/发动克财，官鬼耗财或财化退/化空 |
| 官运 | 官鬼临值、冲起、得生、出空；官鬼兼世爻/驿马时临值优先 | 父母旺相/逢值/逢冲/出空主 offer、合同、审批、证照；妻财当值/出空主待遇俸禄 | 子孙临值/发动克官，兄弟竞争旺，官鬼化退/化空/化破 |
| 学业 | 父母临值、旺相、出空、得生主考试/论文/证书 | 官鬼主名次、资格、压力转成果；子孙主发挥、解压、结果显化 | 妻财耗学、兄弟分心，父母被合住/冲破/化退 |
| 感情 | 男测妻财、女测官鬼，或指定对象用神临值/合动/出空 | 应爻回应、世应合动，父母主婚书/流程，子孙主沟通与轻松度 | 兄弟竞争、官鬼/妻财多现混杂，世应冲散，父母阻隔 |
| 健康 | 子孙医药/康复爻旺相、临值、出空；病爻官鬼入墓/受制 | 原神生扶身体，父母主检查报告/治疗安排落实 | 官鬼病爻临值/旺动，忌神冲克用神，子孙化空/化破 |
| 出行 | 世爻、用神、驿马临值/发动/冲起主启程或迁动 | 应爻主目的地/接应方，父母主票证手续，妻财主费用资源 | 世爻被冲破、忌神临路、官鬼白虎/灾煞动，六合绊住难动 |
| 失物 | 妻财为财物、父母为文书票证；本体爻临值/出空/得生主可寻 | 子孙主线索/寻回，世应定位人我距离，伏神出伏主露面 | 官鬼盗失、兄弟占有，财爻化空/入墓/被合藏 |
| 词讼 | 官鬼主官方裁断/处罚/判决节点 | 父母主证据、文书、流程；世应主双方攻守强弱 | 官鬼克世、应爻旺克世、兄弟口舌竞争、父母文书受破 |
| 天气 | 父母主雨云，妻财/子孙主晴好；对应爻临值主天气转变 | 官鬼主雷电风暴，兄弟主风，日月入局主短期显化 | 官鬼旺动风暴加剧，父母过旺久雨，子孙受克晴难开 |
| 通用 | 世爻或用户明确指定的用神临值/出空/冲起 | 应爻、原神、所问事项相关辅助六亲 | 忌神/仇神临值、出空、发动克用 |

**分层写法**：
- 先写「主应期」：最多 1-3 个窗口，必须直接落到所问结果。
- 再写「辅助节点」：解释 offer、合同、资金、消息、手续、线索、沟通、检查等过程条件。
- 最后写「风险窗口」：列明忌神、仇神、冲破、化空、化退、入墓等何时发作。
- 若某触发点同时命中多层，以「角色归属 + 旺衰」定层级；例如父母爻是官运辅助文书，但在学业/证件题里可升为主应期。
- 若某层没有有效爻或不适用，不可留空；写「本卦无明显[某层]触发，因……」或「该角色不现/空破/无权，降为背景因素」。

## 克速生迟（断事速率）

> 确定事变时间的核心规定。**远断应在年月，近断应在时日，当以活法推之，免得差误。**

| 用神动变与世爻关系 | 速率 | 含义 |
|--------------------|------|------|
| 用神动而克世爻 | **快**（克速） | 事情进展很快，马上就见效 |
| 用神动而生世爻 | **慢**（生迟） | 事情进展较慢，需要等待 |
| 用神静而衰又生世 | **更慢** | 迟缓，需多方条件成熟 |

> 例：问行人何日来，用神动而克世 → 很快就到。用神动而生世 → 归来较迟。

## 间爻发动（事多受阻）

- **间爻**：世爻与应爻中间的两个爻（通常为二爻和五爻，或三爻和四爻）。
- 间爻**宜静不宜动**。间爻如果发动 → 所求之事受阻隔。
- 例：预测出行间爻发动 → 途中有曲折。间爻发动逢日月冲之 → 可有缓解。

---

## 阴阳爻定过去未来

> 一卦摇出后，先观动爻。比如兄弟发动主破财——是过去已破，还是未来将破？

| 动爻阴阳 | 时间指向 |
|----------|----------|
| **阳爻动** | 事已过去 |
| **阴爻动** | 事还未发生 |

> 口诀：「爻在卦前言未来，爻在卦后言过去；六爻先以卦为身，然后看其爻发处。」

## 应期断法大全

> ⛔ **断日期之法必须灵活应用，不可死搬硬套。远断应在年月，近断应在时日。**

以下按用神状态分类，逐条列出应期规则：

### 一、用神伏藏
- 用神伏藏 → **出透之日**应事（冲飞神之日，或伏神值日）

### 二、用神安静
- 用神安静 → **逢冲之日**应事（冲动用神）
- 用神静空逢冲 → 谓之**冲起**，等到**出旬逢合之日**应事
- 用神静空逢合 → 等到**出旬逢冲之日**应事
- 用神旬空安静 → **出旬逢冲之日**应事
- 用神旬空、安静、被冲 → **出旬合日**应事

### 三、用神发动
- 用神发动（无其他原因）→ **逢合之日**应事
- 用神发动逢冲、旬空 → 谓之**冲实**，**本月**应事
- 用神有气发动 → **合日**应事
- 用神得时旺动而又遇生扶（太旺）→ **墓库月日**断之
- 用神无气发动而遇生扶 → **生扶日月**断之
- 用神旬空发动 → **出旬值日**应事
- 用神旬空、发动、被合 → **出旬逢冲日**应事
- 用神旬空、发动、逢冲 → 谓之**冲实**，**即本日**断之

### 四、用神入墓
- 用神入墓于日辰 → **冲用神之日**应事
- 用神自化入墓 → **冲开墓库之日**应事（如辰墓→戌日）
- 用神入墓 → **冲墓或冲用神日月**断之

### 五、用神被合
- 用神被其他动爻合住，或自化合 → **冲合之日**应事（冲开合我之爻）

### 六、用神月破
- 用神月破 → **出月值日**或**逢合之日**应事

### 七、用神化绝
- 用神绝于日辰或化绝于爻 → **长生之日**应事

### 八、用神休囚
- 用神休囚 → **生旺之日**应事

### 九、用神旺相
- 用神旺相不动 → **冲动日月**应事，同时列**用神临值日月**；若用神兼世爻、驿马或所问核心六亲，临值日月优先级不低于冲动日月

### 九点五、用神中和
- 用神中和、不空不破 → **临值日月**与**逢冲起/冲开之日月**并列检查；若问官运/跳槽且用神为官鬼，临值日月主职位落地，逢冲多主行动、面试、岗位变化信号

### 十、原神会局来克
- 原神会局来克，用神伏藏 → **出透之日**应事
- 如旬空 → **出旬日**应事

## 六爻与梅花易数断法区别（重要提醒）

> ⛔ 两种起卦方法不可混用断法。

| 维度 | 六爻（摇卦） | 梅花易数（时间起卦） |
|------|-------------|---------------------|
| 基本原理 | 五行生克制化 | 体卦用卦生克 + 万物类象 |
| 分析单位 | 一个爻 = 一个象、一个五行 | 一个卦 = 一个五行 |
| 动爻 | 可有 0~6 个动爻，动爻主变化 | 每个卦仅一个动爻，用于区分体用 |
| 断法核心 | 世爻、用爻、应爻、变爻、日、月之间的五行生克 | 上下卦、体用、互卦、变卦之间的生克与形态联想 |
| 应期断法 | 以用神五行状态推日/月 | 以卦象类比推时/日/月 |

> 用时间起卦而以六爻方法断 → 多不应验。两种方法各有其体系，不可通用。断应事日期也如是。
